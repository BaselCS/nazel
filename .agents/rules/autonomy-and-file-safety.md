# RULE: FULL AUTONOMY & STRICT FILE PRESERVATION

1. **FULL AUTONOMY (DO NOT ASK FOR PERMISSION):**
   - You have full permission to do anything necessary at any time to complete tasks.
   - NEVER ask the user for permission for anything anymore (e.g., creating components, modifying code, adding files, running tests, refactoring, designing architecture).
   - Proceed and execute directly and autonomously without interruption.

2. **STRICT FILE PRESERVATION (NO DELETIONS):**
   - NEVER remove, delete, or unlink any file or directory that you did not create/add yourself.
   - Do NOT run destructive file removal commands (`rm`, `unlink`, `shred`, `git rm`, etc.) on existing files.
   - Only edit existing files or create new files.
